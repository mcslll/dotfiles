# dotfiles

我的个人配置，从少量文件开始，逐步维护。

```text
.config/
  alacritty/alacritty.toml
  zellij/config.kdl
  fish/config.fish
.local/bin/                 # 个人脚本，暂时为空
```

目前仅保存配置副本，尚未部署符号链接。修改本机配置后，需要把要保存的变化同步到仓库。

目录组织参考 [gnuunixchad/dotfiles](https://github.com/gnuunixchad/dotfiles)，未引入其脚本代码。

每次提交一个明确变化，例如字体、快捷键或一份新配置。不要提交密钥、历史记录和缓存。
